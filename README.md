# Проект. Инфраструктура онлайн магазина

## Описание
Проект онлайн магазина. В данный момент идет разработка классов для будущих карточек товаров.

## Тестирование
Код покрыт тестами Coverage report: 86%

HTML-отчёт, который показывает, какие строки кода были покрыты тестами, а какие нет в корневой директории

~~~
report.html
~~~

## Установка
1 Клонируйте репозиторий: 
~~~
https://github.com/romanivanov531/Chapter_4.git
~~~

2 Перейдите в папку проекта:  cd ваш_репозиторий

3 Установите зависимости:
~~~
poetry add ...
~~~
Зависимости указаны в файле pyproject.toml


## Реализовано
    1. Класс Category. Дополнительно ведет подсчет количества категорий и количества продуктов
    2. Класс Product.
    3. Реализованы подклассы Product. Интеграрованы проверки классов.
    4. Реализован класс-миксин LogMixin. Выводит информацию продукта при его инициализации.

## Запуск
Запуск проекта происходит через файл: 
~~~
main.py
~~~
